# Rohit Sekh

Software developer at **Clerisy Solutions**, building web and mobile apps with TypeScript, Next.js, NestJS and Angular/Ionic.
Outside work I rebuild things from scratch in Go to learn how they actually work.

### Things I've built

- **[torrent-client](https://github.com/venom-10/torrent-client)**: BitTorrent client in Go with zero dependencies. It handles bencode, tracker announces, the peer wire protocol, and pipelined parallel piece downloads with SHA-1 verification.
- **[search_engine](https://github.com/venom-10/search_engine)**: search engine in Go with a tokenizer and stemming, an inverted index, BM25 ranking, snippet extraction, and an interactive REPL.
- **[distributed-job-queue](https://github.com/venom-10/distributed-job-queue)**: job queue built on NestJS, Redis and PostgreSQL without BullMQ. It has atomic Lua-script locks, heartbeats, exponential-backoff retries, and a dead-letter queue.
- **[habbit-tracker](https://github.com/venom-10/habbit-tracker)**: desktop habit calendar built with Go, Wails and SQLite.
